# Next.js 15 Agent Guide

This project uses Next.js 15 with App Router, TypeScript, and Tailwind CSS.

## Key Principles
- Use the App Router (`src/app`).
- Default to Server Components, use `"use client"` only when necessary.
- Use TypeScript for all components and logic.
- Use Tailwind CSS for styling.
- Follow the established file structure.

## File Structure
- `src/app`: Routes and layouts.
- `src/components`: Reusable React components.
- `src/components/ui`: Shadcn UI components.
- `src/lib`: Utility functions.
- `src/hooks`: Custom React hooks.
- `src/shared`: Shared constants and types.
- `public`: Static assets.
